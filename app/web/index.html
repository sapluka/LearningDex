设置

B 站登录信息 可选

通常可以留空。SESSDATA 是 B 站登录凭据；Cookie 文件保存浏览器在 B 站的访问和登录状态。视频需要登录，或下载提示需要登录信息时，再填写任意一项；有效的 Cookie 文件优先使用。

获取 SESSDATA · Chrome / Edge

  1. 在浏览器打开 B 站，并登录自己的账号。
  2. 按 F12，进入「应用程序 / Application」→「存储 / Storage」→「Cookies」，选择 B 站域名。
  3. 找到名称为 SESSDATA 的一行，复制「值 / Value」列，粘贴到上面的登录凭据框。

获取 cookies.txt · Chrome / Edge

  1. 安装 Cookie 导出扩展，例如 Get cookies.txt LOCALLY，然后打开并登录 B 站。
  2. 在扩展中选择仅导出当前 B 站的 Cookie，以 Netscape 格式保存为 cookies.txt；不要导出所有网站。
  3. 在文件资源管理器中右键复制该文件的完整路径（Windows 10 可按住 Shift 再右键），粘贴到上面的文件框，去掉两端引号。

这些信息代表你的登录状态，请勿公开或发给他人。失效后重新获取；填写后点击「保存」，本次运行使用。
